1. Pick a Week

Weeks are Sunday–Saturday buckets built from each game's actual date (not the schedule's week field, which isn't reliably set on every game).

2. Generate Salaries

Salary = career acesBPI blended with a small (≤25%, ramping up over the first 10 games this season) weight for this-season acesBPI, then priced against a $6,500 midpoint anchored to acesBPI = 50 (league average) — below-average ratings are percentile-ranked into $3,000–$6,500, at/above-average ratings into $6,500–$10,000. This keeps "50" meaning the midpoint salary every week, regardless of how that week's pool happens to be distributed. Pitchers are flat-priced at $5,000 since acesBPI doesn't reflect pitching. Salary cap for a lineup: $50,000.

3. Score a Completed Week

Pulls that week's playerStats/pitchingStats game lines for every player in the published salary pool, totals fantasy points, and locks in dfsScores. Run this after all of that week's games have been submitted via Submit Stats.
