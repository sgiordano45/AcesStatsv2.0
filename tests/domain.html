Standings by season

Pass = js/domain/standings.js gives the same order, W-L-T and runs allowed as current-season.html (the chain: H2H for 2 teams, runs allowed for 3+, then run differential). One intended difference: a winner stored as a team ID ('master_batters', all of 2019 Summer) now counts. In a season that has those, the old pages run with them read as names, and the season is tagged "explained". The other columns show where the old pages disagree with current-season on the same data. playoffs, bracket, projections and playoff-clinching only ever run on the current season, so their results on past seasons show what they would do, not what anyone saw.
